사용법

  1. 서류 이름 입력작성할 세무·회계 서류의 이름을 입력 칸에 칩니다. 글자를 치는 즉시 서식이 펼쳐집니다.
  2. 서류 선택비슷한 서류가 있으면 서식 위의 버튼에서 고릅니다.
  3. 엔터 키로 작성 시작엔터 키를 누르면 같은 화면에서 AI가 초안을 위에서부터 작성합니다.
  4. 의뢰인 정보 자동 기입성명·주소·전화번호·이메일은 PDV에서 가져와 파란 칸(PDV 표시)에 채웁니다. 고칠 수 있습니다.
  5. 빈 칸 입력과 저장남은 빈 칸을 채우면 내 서류 목록에 자동 저장됩니다. 서류 위·아래의 “제출 결과 예상”으로 접수 결과를 미리 가늠할 수 있습니다.

사이트의 특징

  1. 세무사·공인회계사 서류를 한 곳에서신고서·조정계산서·감사 관련 서류 등을 한 화면에서 작성하고, 작성한 서류의 제출 결과(승인·보정·수정)를 법적 근거와 함께 미리 가늠합니다.
  2. 데이터의 해외 유출 없음국산 LLM과 국내 서버를 사용하므로 데이터가 해외로 나가지 않습니다.
  3. 기밀 누출 우려 없음모든 데이터는 사용자의 데이터 금고에 저장하고 서버에는 저장하지 않습니다.
  4. 의뢰인 정보 자동 기입인적사항은 PDV에서 가져오므로 매번 묻지 않습니다.
  5. 페이지 이동 없이입력, 작성, 검토가 모두 한 화면에서 이루어집니다.
